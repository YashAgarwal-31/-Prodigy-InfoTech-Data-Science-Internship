## About the Internship

I completed a **Data Science Internship at Prodigy InfoTech from 1 July 2025 to 31 July 2025**. This repository brings all four completed tasks into one organized portfolio, covering data visualization, exploratory data analysis, supervised machine learning, and natural-language sentiment analysis.

## Internship Projects

| Task | Project | Core work | Notebook |
|---|---|---|---|
| **01** | Population Distribution Visualization | Bar charts, histograms, distribution analysis, and interpretation | [Open Notebook](Task-01-Population-Visualization/PRODIGY_DS_01.ipynb) |
| **02** | Titanic Data Cleaning & EDA | Data-quality checks, missing-value analysis, feature relationships, and visual exploration | [Open Notebook](Task-02-Titanic-EDA/PRODIGY_DS_02.ipynb) |

## Project Details

### Task 01 — Population Distribution Visualization

**Objective:** Create clear bar charts and histograms for categorical and continuous variables in a population dataset.

- Loaded and inspected country-level population data.
- Prepared relevant variables for visualization.
- Used bar charts and histograms to study distributions.
- Interpreted demographic patterns and communicated the findings visually.

**Files:** [Notebook](Task-01-Population-Visualization/PRODIGY_DS_01.ipynb) · [Dataset](Task-01-Population-Visualization/population.csv)

### Task 02 — Titanic Data Cleaning and Exploratory Data Analysis

**Objective:** Clean the Titanic passenger dataset and investigate the factors associated with passenger survival.

- Examined columns, data types, duplicates, and missing values.
- Prepared the dataset for reliable analysis.
- Performed univariate and multivariate exploratory analysis.
- Visualized relationships between passenger attributes and survival outcomes.

**Files:** [Notebook](Task-02-Titanic-EDA/PRODIGY_DS_02.ipynb) · [Dataset](Task-02-Titanic-EDA/Titanic.csv)

### Task 03 — Bank Marketing Decision Tree Classifier

**Objective:** Build a decision tree model that predicts whether a customer will subscribe to a product or service using demographic and behavioral attributes.

- Explored and prepared the bank-marketing dataset.
- Processed categorical and numerical variables for modeling.
- Trained a supervised decision tree classifier.
- Evaluated predictions and interpreted the model's decision logic.

**Files:** [Notebook](Task-03-Decision-Tree/Decision%20Tree%20Classifier.ipynb) · [Dataset](Task-03-Decision-Tree/bank-additional.csv)

### Task 04 — Social Media Sentiment Analysis

**Objective:** Analyze social-media text to understand sentiment patterns and public opinion about topics, products, and brands.

- Loaded separate training and validation datasets.
- Inspected sentiment classes and prepared the text data.
- Analyzed sentiment distributions and recurring patterns.
- Created visualizations that communicate audience perception and emotional tone.

**Files:** [Notebook](Task-04-Sentiment-Analysis/Twitter%20Sentiment%20Analysis.ipynb) · [Training Data](Task-04-Sentiment-Analysis/twitter_training.csv) · [Validation Data](Task-04-Sentiment-Analysis/twitter_validation.csv)

## Run Locally

```bash
git clone https://github.com/YashAgarwal-31/-Prodigy-InfoTech-Data-Science-Internship.git
cd ./-Prodigy-InfoTech-Data-Science-Internship
python -m venv .venv
```

```bash
# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
jupyter notebook
```

Open any task folder and run its notebook cells in sequence. Each required dataset is stored beside its corresponding notebook.
